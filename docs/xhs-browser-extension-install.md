# 小红书本机抓取扩展安装说明

这个扩展让抓取任务在使用者自己的 Chrome 或 Edge 中运行。网站服务器不登录小红书、不搜索或打开小红书详情，也不代理小红书图片和视频。抓取时会打开一个可见标签页，结果只写入当前网站在这台浏览器中的本地存储。

## 0.1.31 主动读取抖音懒加载轮播图

- 点击上传后会逐张切换当前抖音图文的轮播，把后续懒加载图片读取完整后再上传。
- 轮播过程锁定当前 `modal_id` 和正文，并优先选择图片右侧最近的翻页控件，避免误入下一条主题或操作栏。

## 0.1.30 合并当前抖音作品中已挂载的轮播图

- 页面数据只有首图时，会比较当前 `modal_id` 对应作品容器里的图片，采用数量更完整的一组。
- 图片范围锁定在当前作品 ID，前后相邻主题仍然隔离，不会把下一条作品混入图库。

## 0.1.29 修复抖音优先命中首图预览记录

- 同一作品同时存在搜索预览和详情记录时，会比较全部同 ID 候选，优先采用图片最完整的记录。
- 详情数据位于页面脚本时同样会与搜索预览比较，不再因为先读到一张封面就提前停止。

## 0.1.28 修复无详情 ID 时抖音只识别首图

- 抖音搜索页没有 `modal_id` 时，会用当前弹窗正文或首图关联页面数据中的同一作品。
- 完整图片列表从匹配的作品记录读取，不再受抖音只渲染当前首图影响，同时继续隔离前后相邻作品。

## 0.1.27 修复抖音与 TikTok 同步卡住

- 抖音搜索页即使地址不再带 `modal_id`，只要当前有可见图文详情弹窗，也会按弹窗内容识别和上传。
- 抖音与 TikTok 图片改为分批并行下载，并为单张请求增加超时；某个 CDN 请求挂起时不会再阻塞整次同步。

## 0.1.26 统一线上与本机安装包

- 下载页只提供一个通用安装包，同时支持 `https://xhstw.qycm.top` 和 `http://127.0.0.1:3000`，不再区分线上包和本机包。
- 插件分别保存线上与本机工作台的上传授权；两边同时打开时优先上传到本机工作台，避免成功提示后在当前库中找不到内容。

## 0.1.25 修复本机工作台未连接插件

- 下载按钮改由服务器按当前工作台地址选择安装包，即使页面脚本尚未加载，本机也不会再下载到线上权限包。
- 工作区的 `扩展` 目录改为直接绑定 `http://127.0.0.1:3000`，重新加载后即可取得本机上传授权。

## 0.1.24 修复本机上传进入线上图库

- 本机工作台会下载只绑定 `http://127.0.0.1:3000` 的插件包，线上工作台继续下载只绑定 `https://xhstw.qycm.top` 的插件包。
- 插件的上传目标与当前工作台严格对应，避免 TikTok、抖音图文上传成功后在当前图库中找不到。

## 0.1.23 修复 TikTok 正文图被误判为评论图片

- TikTok 正文图的无障碍说明包含 `Comments` 时不再被评论图片过滤器误删。
- 详情弹窗可以同时识别当前正文图片和文案。

## 0.1.22 恢复 TikTok 详情上传条

- 从搜索结果打开 TikTok 图文详情弹窗时，上传条会正常显示。
- 优先读取当前可见详情弹窗，同时继续隔离搜索列表和相邻主题。

## 0.1.21 修复 TikTok 详情串图与串文案

- 按当前详情地址里的 `photo` ID 锁定 TikTok 主题，不再上传前后主题的图片。
- 图片、标题和正文统一从当前主题读取，避免文案与详情页不一致。

## 0.1.20 修复抖音详情图识别

- 按当前详情的 `modal_id` 锁定作品，不再误取轮播中的上一条或下一条。
- 同一张图的封面地址和原图地址只保留一份，并优先上传原图。

## 0.1.14 仅在图文详情显示上传

- 搜索页、首页和信息流不再出现底部上传条。
- 只有点开小红书、抖音或 TikTok 的单条图文详情后才会出现“上传到爆款选题库2”。

## 0.1.13 上传到爆款选题库2

- 打开小红书、抖音或 TikTok 的图文详情时，页面底部会出现“上传到爆款选题库2”。
- 点击后把当前页的图片和文案写入中台的爆款选题库2，不会进入内容库1。
- 使用前请先在图文生产中台登录一次，插件才会取得上传授权。
- 网页和扩展需要一起升级到 0.1.13。

## 0.1.12 自定义抓取数量

- 关键词数量不再限制为 2 个。
- 每个关键词不再限制为 5 条，用户填写的数量会作为抓取目标。
- 不可浏览、重复或不符合筛选条件的候选会继续向后补抓；确实不足时会显示实际数量和目标数量。
- 详情间隔、关键词间隔、单任务锁和风控冷却仍然保留。

## 0.1.11 本机媒体保存

- 新抓取的正文图片、视频和视频封面会下载到当前浏览器站点数据中的专用 IndexedDB。
- 媒体仍显示在“爆款选题库”卡片内，不会进入左侧“素材库”。
- 清除该网站的浏览器站点数据会同时清除这些本机媒体文件。
- 删除选题会删除对应本机媒体；保留、取消保留和拒绝不会删除媒体。
- 单个媒体失败时，其余成功媒体和选题文案仍会保留，批次继续执行。
- 网页协议和扩展必须同时升级；旧扩展会显示“版本过低”。

### 从旧版升级

1. 先等待新版网页部署完成；网页和扩展协议必须同为版本 3。
2. 在 `chrome://extensions` 或 `edge://extensions` 停用或移除旧的解压扩展。
3. 解压工作台下载的 0.1.31 ZIP，开启开发者模式并点击“加载已解压的扩展程序”。
4. 选择解压后直接包含 `manifest.json` 的文件夹。
5. 后续替换文件时先在扩展管理页点击“重新加载”，再刷新生产网站。
6. 回到“爆款选题库”，确认状态显示“本机抓取已连接”后再开始抓取。

## 安装

1. 下载扩展 zip，并完整解压到一个固定目录。后续不要移动或删除这个目录。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展”，选择刚才解压且直接包含 `manifest.json` 的目录。
5. 在同一个浏览器中打开小红书并完成登录。
6. 重新加载生产网站，确认选题页显示“本机抓取已连接”。不需要点击扩展图标。
7. 第一次请只选择 1 个关键词、每个关键词 1 条，然后点击一次“开始抓取”。

执行期间不要关闭扩展创建的小红书标签页。任务成功后扩展会关闭该标签页并返回网站；如果出现登录、验证码或安全限制，标签页会保留，方便人工处理和诊断。

## 访问频繁或 300013

如果页面显示“安全限制”“访问频繁”或错误码 `300013`：

1. 立即停止当前抓取，不要连续重试。
2. 保留小红书标签页，核对页面上的真实提示。
3. 等待网站显示的 60 分钟本机冷却结束后再试。
4. 不要通过反复卸载、重装扩展或刷新页面来绕过冷却。

冷却只记录在发生问题的这台浏览器中，不会影响其他用户的浏览器。

## 更新

1. 在扩展管理页移除旧扩展。
2. 下载并解压新的 zip 到新目录。
3. 再次选择“加载已解压的扩展”。
4. 重新加载生产网站，确认显示“本机抓取已连接”。

## 移除

在 `chrome://extensions` 或 `edge://extensions` 中找到“小红书本机抓取助手”，点击“移除”。移除后网站会显示“未安装本机抓取扩展”，抓取按钮不可用；已有本地选题不会自动删除。

## 权限范围

扩展只访问打包时指定的网站 Origin 和 `https://www.xiaohongshu.com/*`，只申请 `storage` 权限。它不申请 Cookie、历史记录或全站访问权限，也不会执行网站下发的任意脚本。
