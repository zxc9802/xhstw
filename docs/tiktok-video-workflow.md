# TikTok 爆款视频

工作台导航新增「TikTok 爆款视频」，地址 `/tiktok`。

## 使用方法

1. 配置 TikHub 后输入关键词或完整公开视频链接采集，或导入 JSON/CSV。TikHub 优先，失败时使用已配置的 ScrapeCreators 备用；仅配置其中一家也可采集。采集的是候选样本，不是全站清单。单批关键词最多 50 条，指定链接最多 20 条。每条视频核验创作者国家与粉丝；有后续页时可继续下一批。
2. 账号国家下拉默认马来西亚（MY），可选择其他国家/地区或「国家不限」。指定国家时归属缺失仍待核实；不限时不以国家作为命中条件。默认粉丝 ≤ 20,000、播放 ≥ 50,000、近 7 天、播放/粉丝比至少 3 倍且上不封顶、类目不限。可切换近 3 天、严格 3–5 倍或至少 5 倍及精确内容类目。挂车状态不采集、不展示、不参与筛选；旧导入数据可保留该字段。缺少必要字段显示「待核实」；已知不符合显示「不符合」。0 粉丝不能计算倍数。倍数不是粉丝增长率。
3. 点击「拆解与创作」→「自动转录与音画拆解」，自动下载经过视频/作者身份核验的原媒体，校验轨道与时长、完整解码，再将整段压缩视频交给 OpenLux。页面显示原语言人声转录、原片画面/声音/字幕/剪辑时间轴及节奏分析。当前支持单条 ≤180 秒、原媒体 ≤64 MiB、处理后模型输入 ≤18 MiB；时间戳与识别文字近似，需核对。
4. 可修正自动转录或补充真实观察，选择马来语、英语或中文和时长，填写已确认的产品事实及拍摄要求。生成原创标题/发布文案/完整口播、连续新拍分镜、准备清单及审核事项。原片音画依据只能从服务端已验证的记录读取并与当前来源绑定，旧文字模式仍可使用，页面明确标注依据。原片价格及优惠不能代替当前产品事实。
5. 导出完整 JSON（候选、采集说明、原片分析和拍摄包）或单条 Markdown（含生成时的原片分析快照及新拍脚本）。浏览器记录可导出备份并恢复，有效的较新数据优先，无效或错配记录提示并跳过。服务端音画记录在 `outputs/tiktok-media/`；迁移服务器后可查看备份，但基于媒体重新生成需再次分析。临时原片和上传副本处理后精确删除，保留来源哈希、分析与请求状态。

采集使用后台任务：POST 保存任务后快速返回 202，页面通过短 GET 请求获取进度与结果，避免整批采集超过代理连接时限。任务编号在提交前保存到浏览器，断线或刷新后点击「继续获取结果」只查询原任务，不重新调用付费接口。同一用户、同一任务编号重复提交不会重复执行；其他用户不能读取该任务。旧页面需刷新后使用此流程。

任务与完整结果保存在 `outputs/tiktok-collection-jobs/`。当前单实例部署可从磁盘取回结果；Zeabur 如需跨重新部署保留，须将 `/app/outputs` 挂载持久化硬盘。运行中的进程被停止不会自动续跑，超过 3 分钟标为中断，避免不知情地重复计费；多实例须共享该目录。历史同步请求未保存的响应无法从新任务机制恢复。采集接口按上游请求计费，浏览器断线不等于上游取消或退款。

2026-10-16 验证：相关 70 项测试与生产构建通过。生产模式模拟采集运行 64.7 秒，首次 POST 在 245 毫秒返回 202，最终取回 20 条候选；重复提交和服务器重启后查询均未新增上游调用。另覆盖首次 POST 响应丢失、查询暂时断线、用户隔离及中断任务不自动重跑。此次验证未调用真实付费接口。

## 服务配置

在服务器 `.env.local` 配置后重启：

```dotenv
SCRAPECREATORS_API_KEY=你的ScrapeCreators密钥
TIKHUB_API_KEY=你的TikHub密钥
TIKTOK_REWRITE_API_KEY=你的OpenLux密钥
TIKTOK_REWRITE_URL=https://api.openlux.ai/v1/chat/completions
TIKTOK_REWRITE_MODEL=gemini-3.8-flash
TIKTOK_FFMPEG_BIN=
TIKTOK_FFPROBE_BIN=
TIKTOK_MEDIA_PROXY=
```

采集、粉丝、账号国家及原片详情优先使用 TikHub；请求失败、业务状态异常（含 `hit_shark`）或详情身份校验失败时尝试已配置的 ScrapeCreators，切换原因进入采集说明。正常空列表不触发备用；两家均异常时明确失败。两家的搜索游标不能混用，下一批同时携带 `provider` 并沿用该来源；切换来源时从首批重新开始并按视频 ID 去重，不把旧游标传给另一家。上游整页超过所选批量时仅处理本批上限，并提示超出部分未处理。内容类目仅通过 TikHub Web 接口补采，缺失时待核实。

服务器需安装 FFmpeg 与 FFprobe，在 PATH 上可运行或配置上面的可执行文件路径。TikTok CDN 直连不可达时，可设置 `TIKTOK_MEDIA_PROXY` 为已存在的 HTTP 代理地址；代理仅用于媒体下载，两家服务的密钥均不转发到媒体域名。当前机器使用已开启的本机代理，不改变 Windows 全局代理设置。

凭据仅在服务器使用。TikTok 模型配置独立于原有图文模型，不需要改变 `COPY_MODEL_PROVIDER`。需要可用的服务权限和额度。TikHub 请求不接入当前主站积分系统，上游按账户计费；转录/音画分析及文案模型保留主站积分预留、结算及失败释放流程。缺配置、HTTP/业务错误、媒体校验、模型格式或时长错误都会提示，不返回模拟成功。整段视频输入沿用当前端点实测有效的 `image_url` + `data:video/mp4`；其他服务商须单独验证兼容性，HTTP 200 不能证明模型读到了视频。

## 数据导入

- 模板：`public/templates/tiktok-videos.json`、`public/templates/tiktok-videos.csv`，页面可下载。
- 字段：`id,url,author,description,followers,views,publishedAt,country,hasProductLink,category,transcript,source`。
- `id` 必须为精确数字字符串；JSON 的数字 ID 会被拒绝，防止超过 JavaScript 精度。CSV 请避免先经 Excel 将 ID 转成数值或科学计数法。
- `url` 是 `https://www.tiktok.com/@作者/video/视频ID`，必须与 ID 和作者对应。短链接请先打开获取完整视频地址。
- 粉丝/播放用完整非负整数，未知用 JSON `null` 或 CSV 空白，不能用 0 替代。平台的 `1.2K`、`2万` 等近似显示数不能作为精确筛选依据。
- `publishedAt` 使用含时区的 ISO 时间，例如 `2026-10-13T08:00:00+08:00`；纯日期按 UTC 零点处理。`capturedAt` 选填，有值时必须是有效 ISO 时间，不可用导入时间冒充旧数据采集时间。
- `country` 使用账号国家代码，例如 `MY`；不知道就留空，不能按语言或搜索关键词推断。用户导入的国家字段是用户提供的来源事实，没有自动再次核验。
- `hasProductLink` 为布尔值 `true/false` 或未知。JSON 原始响应中仅带商品 ID 的锚点证明挂车；没有锚点字段时未知。类目必须来源明确，不从文案自动猜测。
- JSON 可用记录数组、工作台导出文件或 TikHub `data.aweme_list` / `data.data[].aweme_info` 响应；无效行会列出原因，其他合法行仍可导入。单次最多 500 条/5 MB。
- 重复视频以较新的采集时间为准，不用旧文件覆盖新数据。修改筛选后按当前时间重新计算发布时间范围。

## 采集边界

ScrapeCreators 备用接口为 `/v1/tiktok/search/keyword`、`/v2/tiktok/video`、`/v1/tiktok/profile` 和 `/v1/tiktok/profile/region`。TikHub 主接口为 `fetch_general_search_result`、`fetch_one_video_v3`、`handler_user_profile`、`fetch_user_country_by_username` 和 Web `fetch_post_detail_v2`。详情请求地区采用所选国家，不限时使用默认请求地区 MY；请求地区不能证明账号归属，归属仍由独立国家接口核验。ScrapeCreators 搜索的 `region` 是代理地区，TikHub 搜索没有地区参数；均先取得候选再按核实的账号国家筛选，不能保证任一国家全站覆盖或足量命中。切换国家会重置下一批游标。音画采集优先用视频自身的已知账号国家，未知时使用默认请求地区。上游按近一周搜索；选近 3 天时在本地精确过滤。账号国家不能证明实际观众地区。

国家/地区代码来自 [Unicode CLDR](https://github.com/unicode-org/cldr-json/blob/main/cldr-json/cldr-core/supplemental/territoryInfo.json)，常用国家置前。选项不保证上游在所有地区均能取得媒体；上游不支持或读取失败会提示，归属字段不会被所选国家覆盖。

关键词搜索每批最多请求五页，检测重复 cursor 与重复记录，不把返回少量数据视为凑足数量。来源字段及后续游标随 JSON 导出。粉丝和国家接口按用户名绑定身份，并检查返回的 sec UID；错配或无法读取时保留待核实。详情嵌入的零粉丝不作为真实零；有效的非零视频粉丝字段可在资料接口未返回时使用。视频内容类目只取身份一致的 Web `diversificationLabels`，不把商品类目冒充视频类目。响应仅保留所需公开字段，不返回上游 Cookie、会话令牌或签名媒体链接。

参考：[ScrapeCreators 搜索](https://docs.scrapecreators.com/v1/tiktok/search/keyword/)、[ScrapeCreators 账号国家](https://docs.scrapecreators.com/v1/tiktok/profile/region/)、[TikHub 接口说明](https://tikhub.io/tiktok-api)、[TikHub OpenAPI](https://api.tikhub.io/openapi.json)。

## 当前不能完成

- ScrapeCreators 和 TikHub 均未配置时不能真实抓取，未配置 OpenLux 时不能真实 AI 生成。自动化契约测试与真实服务验收分别记录。
- 超过资源限制的长视频暂不能完整处理；不保证逐字转录、快速动作、小字或所有时间点完全准确。没有可辨人声时明确显示未识别人声，不生成假逐字稿。未分析原片的文字模式不能当作已观看视频的证据。
- 不能保证全站全类目覆盖、实时榜单、足量命中、精确观众地区或完整内容类目字段。
- 未实现定时监控、自动拍摄、自动剪辑、发布或流量保证。
- 马来语地道程度、产品事实、时长适配和发布内容需人工核对。
