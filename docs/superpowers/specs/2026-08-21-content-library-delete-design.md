# 内容库逐条删除设计

## 目标

内容库中的每条内容都能从卡片视图、表格视图和详情抽屉永久删除。删除行为同时覆盖腾讯云 COS 内容和浏览器旧内容，并保持现有页面布局和交互风格。

## 删除入口

- 卡片视图：每张内容卡片底部显示红色“删除”按钮。
- 表格视图：每行操作栏显示删除图标。
- 详情抽屉：底部操作栏显示红色“删除”按钮。
- 删除入口对 COS 内容和浏览器旧内容都可用。
- 点击后使用浏览器确认框二次确认，并提示记录及图片删除后不可恢复。

## 数据处理

### COS 内容

调用现有当前成员专属的内容删除接口。服务端根据登录成员生成对象路径，只删除该成员对应内容的 `manifest.json` 和清单引用的 COS 图片。

### 浏览器旧内容

从 `content-production-studio-xhs.finished-content` 数组中删除指定 ID 的原始记录，并清理该记录通过 `cps-image://` 引用的 IndexedDB 图片。不会写入或迁移新的内容。

## 页面状态

删除成功后：

- 从当前内容列表移除该条内容；
- 如果详情抽屉正在显示该条内容，则关闭详情；
- 从多选 ID 中移除该条内容；
- 清理该条内容的浏览器图片解析结果和发布目标临时状态；
- 显示“内容已删除”。

删除失败时保留原内容和页面状态，并显示具体错误。删除进行中禁用该条内容的所有删除入口，避免重复提交。

## 测试与验收

- 纯函数测试验证：删除一个浏览器旧内容时保留其他原始记录，并返回待清理的本地图片引用。
- 页面契约测试验证：卡片、表格和详情均提供删除入口，而且删除逻辑同时包含 COS 与浏览器分支。
- 现有服务测试继续验证：COS 删除仅作用于当前成员的清单和图片。
- 运行完整测试套件与生产构建。
- 验收标准：任意一条 COS 或浏览器旧内容均可在三个入口删除，刷新后不会重新出现，其他内容不受影响。
