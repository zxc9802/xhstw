# 内容库兼容显示浏览器旧内容设计

## 目标

内容库同时显示当前成员的 COS 内容和当前浏览器中已有的旧内容。以后从内容生产页保存的新文字与图片仍只写入 COS；旧数据不迁移、不删除，也不继续写回浏览器存储。

## 方案

页面加载时并行读取：

1. 通过现有鉴权接口读取当前登录成员的 COS 内容。
2. 从旧键 `content-production-studio-xhs.finished-content` 只读加载浏览器旧内容。

两组数据按内容 ID 合并；ID 相同时保留 COS 版本。旧内容带“浏览器旧内容”来源标记。旧图片继续通过现有 IndexedDB 图片引用解析后显示。

## 行为边界

- COS 内容：支持查看、复制、导出和从 COS 删除。
- 浏览器旧内容：支持查看、复制和导出；不提供编辑、删除或写回本地操作。
- 内容生产页：保持现状，新成品只保存到 COS。
- 读取旧数据失败时：COS 内容仍正常显示，并提示旧内容读取失败。
- 不执行 `localStorage.removeItem`、`localStorage.clear` 或 IndexedDB 数据库删除。

## 备选方案

- 恢复旧内容库的本地编辑和删除：会重新引入本地写入，违背“以后只存 COS”，不采用。
- 把旧内容迁移到 COS：用户已明确不需要迁移，不采用。

## 验证

- 回归测试确认内容库读取旧存储键，同时没有本地写入操作。
- 测试确认 COS 与旧内容同 ID 时只显示 COS 版本。
- 测试确认旧 IndexedDB 图片引用可解析用于预览和显式导出。
- 运行内容库/COS 针对性测试、全量测试和生产构建。
