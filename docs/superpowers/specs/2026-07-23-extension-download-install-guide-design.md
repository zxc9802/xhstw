# 小红书扩展下载与安装说明设计

## 状态

- 日期：2026-07-23
- 状态：设计与书面规格已由用户确认
- 适用范围：全站顶部栏的浏览器扩展下载和安装指引

## 目标

让用户在网站顶部栏直接下载当前小红书本机抓取扩展，并能在站内查看 Chrome 和 Edge 的安装、升级及常见问题说明。

## 非目标

- 不修改现有小红书抓取流程、扩展通信协议或扩展权限。
- 不发布到 Chrome Web Store 或 Edge Add-ons。
- 不实现扩展自动安装或自动升级。
- 不增加新的设置页或独立帮助页面。

## 入口与交互

入口固定在全站顶部栏右侧、通知铃铛左侧，与用户截图红框位置一致。

该区域放置两个按钮：

1. 绿色主按钮“下载插件”：点击后直接下载当前版本的完整 ZIP 文件。
2. 白色次按钮“安装说明”：点击后在当前页面打开站内弹窗。

弹窗可以通过右上角关闭按钮、底部“我知道了”按钮或点击遮罩关闭。弹窗不跳转页面，不改变当前业务页面状态。

## 下载产物

网站提供一个静态 ZIP 下载文件，文件名包含扩展版本号。ZIP 解压后的顶层目录必须直接包含：

- `manifest.json`
- `background.js`
- `app-bridge.js`
- `xhs-content.js`
- `shared/protocol.js`
- `shared/collector.js`
- `shared/task-state.js`
- `安装说明.md`

下载产物以仓库现有 `扩展` 目录为来源，保留当前 `0.1.10` 版本和生产网站域名配置。按钮使用普通同源静态下载链接，不新增下载 API。

## 安装说明内容

站内弹窗使用简短的编号步骤说明：

1. 下载 ZIP 并完整解压到固定目录。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展”，选择直接包含 `manifest.json` 的目录。
5. 在同一浏览器登录小红书。
6. 刷新生产网站并确认页面显示“本机抓取已连接”。

弹窗同时说明：

- 升级时先移除旧扩展，再解压和加载新版本。
- 出现 `300013`、访问频繁或安全限制时，应停止重试并等待页面提示的冷却时间。
- 不要通过反复卸载、重装或刷新绕过冷却。

## 组件边界

- `components/layout/AppShell.tsx` 只负责在现有顶部栏挂载扩展入口。
- 新建独立的扩展安装组件，负责两个按钮、弹窗开关和说明内容，避免继续扩大布局组件。
- 打包脚本负责从 `扩展` 目录生成公开下载 ZIP，并校验产物必需文件。

不抽象版本配置系统，不增加远程下载地址或后台接口。

## 错误处理

- ZIP 生成时缺少任一必需文件，打包命令必须失败，避免发布不完整插件。
- 下载使用同源静态文件；若文件未随构建部署，请求自然返回 404，不在前端伪造成功提示。
- 弹窗为纯本地界面，不依赖网络请求。

## 测试与验收

自动验证覆盖：

- 打包脚本生成版本化 ZIP。
- ZIP 包含全部必需扩展文件和安装说明。
- ZIP 内 `manifest.json` 仍为版本 `0.1.10`，且包含生产域名 `https://xhstw.qycm.top/*`。
- 顶部栏包含“下载插件”和“安装说明”入口。
- 下载链接指向实际生成的同源 ZIP。
- 安装说明包含 Chrome、Edge、开发者模式、加载已解压扩展、连接确认、升级和 `300013` 冷却提示。
- 完整测试、TypeScript 检查和 Next.js 构建通过。

人工验收：

1. 在任一业务页面确认两个按钮位于通知铃铛左侧。
2. 点击“下载插件”，确认浏览器下载版本化 ZIP。
3. 解压 ZIP，确认可在 Chrome 或 Edge 中通过“加载已解压的扩展”安装。
4. 点击“安装说明”，确认弹窗内容完整且关闭方式正常。
