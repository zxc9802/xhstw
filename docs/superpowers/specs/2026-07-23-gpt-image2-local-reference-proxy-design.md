# GPT Image 2 本地参考图接入设计

## 目标

让内容生产页面上传的本地参考图可以用于首发渠道 `gpt-image2-low` 图生图，同时保持现有页面操作、异步生成任务和图片结果结构不变。

首发接口只接收 `payload.resources` 中的参考图 URL。页面当前会把本地图片转换为 `data:image/...`，因此服务端需要先把这些图片转换成首发服务器可访问的短期公网 URL。

## 约束

- 当前生产环境是 Zeabur 单实例 Node 服务，图片生成任务也使用进程内存储。
- 不新增 R2、S3、数据库或持久化卷。
- 不修改 Nano Banana、云雾兜底或现有公网参考图行为。
- 不把图片内容、AK、SK 或签名密钥写入日志。
- 服务重启会让进行中的临时参考图失效；这与现有进程内图片生成任务的生命周期限制一致。

## 方案

新增一个进程内临时参考图存储和一个公开读取路由。

服务端收到 `Image 2.0` 生成请求后：

1. 保留现有 `http://` 和 `https://` 参考图 URL。
2. 解析 `data:image/...;base64,...` 本地参考图，校验 MIME、大小和 base64 内容。
3. 将图片字节写入 `globalThis` 上的短期 Map，并生成不可猜测的随机 token。
4. 根据当前请求的公开域名生成 `/api/image/reference/[token]` URL；优先使用受信任的 `X-Forwarded-Host` 和 `X-Forwarded-Proto`。
5. 用这些公网 URL 替换 `sourceImageUrls` 后再启动现有异步图片任务。
6. `openai-image.ts` 按现有首发协议把 URL 数组写入 `payload.resources`，使用 `gpt-image2-low` 提交任务并轮询结果。
7. 生成任务完成或失败后删除本次创建的 token；异常情况下由过期清理兜底。

Nano Banana 请求不经过这一步，继续接收原始参考图数据。

## 临时参考图存储

新增独立模块，负责：

- 注册图片并返回随机 token；
- 按 token 读取图片字节、MIME 和过期时间；
- 主动删除一组 token；
- 每次注册或读取时清理过期记录。

默认生命周期为 30 分钟，与现有图片生成任务的 30 分钟终态保留时间一致。只接受 JPEG、PNG 和 WebP。限制单张图片不超过 10 MB、单次请求累计不超过 40 MB，防止公开接口被大请求耗尽内存。

## 公开读取路由

`GET /api/image/reference/[token]`：

- token 不存在或已过期时返回 `404`；
- 成功时返回原始图片字节和准确的 `Content-Type`；
- 设置 `X-Content-Type-Options: nosniff`；
- 允许上游模型在有效期内重复读取；
- URL 中只包含随机 token，不包含原始图片、文件名或凭证。

该路由必须保持无需登录，因为首发服务器需要直接拉取图片。

## 错误处理

- data URL 格式错误、MIME 不支持或 base64 无效：在创建生成任务前返回 `400`。
- 图片超过大小限制：在创建生成任务前返回 `413`。
- 无法确定公开 HTTPS 域名：返回明确配置错误，不生成首发请求。
- 首发服务器未及时读取或服务重启：现有图片任务记录服务商失败原因，用户重新生成。
- 已创建部分 token 后发生校验错误：立即清理本次创建的全部 token。

## 测试

按测试驱动顺序覆盖：

1. 临时存储可以注册、读取、删除并清理过期图片。
2. 生成路由把本地 data URL 替换为公开临时 URL。
3. 生成路由保留已有公网 URL，并保持参考图顺序。
4. 转换后的 URL 最终进入首发请求的 `payload.resources`。
5. 公开读取路由返回正确字节、MIME 和安全响应头。
6. 非法格式、超限图片、未知 token 和过期 token 返回明确错误。
7. 图片任务完成和失败后都清理临时 token。
8. 现有首发轮询、云雾兜底、Nano Banana 和完整测试套件继续通过。

## 验证边界

自动化测试和构建可以验证请求转换与代码路径。真实图生图仍需要：

- Zeabur 服务配置首发渠道项目编码、AK 和 SK；
- Zeabur 出口 IP 已加入首发白名单；
- 首发服务器能够访问应用公开域名；
- 用一张本地参考图完成一次新的端到端生成。

在完成真实请求前，只能声明代码和协议路径已验证，不能声明首发渠道图生图已在线成功。
