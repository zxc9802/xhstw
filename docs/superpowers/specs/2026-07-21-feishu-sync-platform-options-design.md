# 飞书同步平台选项设计

## 目标

在成品内容库每条内容的“发布平台”选择中，保留“小红书”，并新增 `TikTok`、`Instagram`、`Facebook`。新增平台仅用于同步到飞书时写入“平台”字段，不扩展系统的内容生产、筛选、账号管理或发布能力。

## 方案

在现有平台常量模块中增加用途明确的飞书同步平台列表，内容固定为：

- 小红书
- TikTok
- Instagram
- Facebook

成品内容库只使用该专用列表渲染平台选择。现有全局平台列表继续只包含“小红书”，避免其他页面意外出现尚未接入的平台。

## 数据流

1. 用户在成品卡片选择一个平台。
2. 页面沿用现有状态保存当前内容的选择结果。
3. 用户点击“同步到飞书”时，页面把选择结果作为请求体中的 `platform` 发送到 `/api/feishu/sync-content`。
4. 服务端沿用现有逻辑，将该值写入飞书多维表的“平台”字段。

不新增平台发布请求，不修改成品内容自身的原始平台，也不把新增选项用于筛选、生成或账号管理。

## 兼容与异常处理

- 未主动选择时，继续沿用现有默认值“小红书”。
- 飞书表缺少“平台”字段时，继续遵循现有字段过滤行为，不增加新的错误分支。
- 平台名称使用标准写法 `TikTok`、`Instagram`、`Facebook`，不使用缩写或小写别名。

## 验证

1. 单元测试确认飞书同步平台列表严格等于“小红书、TikTok、Instagram、Facebook”。
2. 单元测试确认现有全局平台列表仍然只有“小红书”。
3. 运行完整测试与生产构建，确认页面编译和现有功能未受影响。
