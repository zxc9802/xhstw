# 图文生产中台本地持久化与图片工作流设计

## 状态

- 日期：2026-07-22
- 状态：用户已选择方案 A，等待书面规格复核
- 适用范围：图文生产、成品内容库、账号管理和产品品牌文案

## 目标

在不增加服务端数据库和对象存储的前提下，让同一台电脑、同一个浏览器中的关键词库、图片生成草稿、生成图片、账号资料和头像能够长期保存，并让部署到 HTTPS 站点后的页面可以把用户选中的图片真实写入用户选择的本地文件夹。

同时修复成品预览自动配图、选图顺序不可调、放大图被弹窗遮挡、成品库本地导出仅为 mock、账号无法上传头像或删除，以及产品品牌仍显示“小红书图文生产”等问题。

## 非目标

- 不建设跨电脑、跨浏览器或跨域名同步。
- 不增加用户登录、服务端数据库、云端对象存储或服务器文件持久化。
- 不删除“平台：小红书”“小红书账号”“小红书图文”等真实业务字段。
- 不改变图片模型、文案模型或小红书平台接入逻辑。
- 不重构与本次需求无关的图文、视频或素材库流程。

## 当前行为与根因

1. 自定义关键词和已删除关键词只保存在 React 内存状态中，组件卸载后会回到硬编码词库；新作品还会从候选数据带入默认已选关键词。
2. 生成图片已经写入 IndexedDB，但图片生成页的文案、P 页面、配置、参考图和提示词等状态没有统一持久化，离开路由后会重新初始化。
3. “保存本地”和成品库“导入本地文件夹”只保存或显示文件夹名称，没有调用浏览器文件写入接口。
4. 打开成品预览时会调用默认分图函数，把全部生成图自动分配给各作品。
5. 已选图片列表按 P 页重新排序，无法保存用户自定义顺序；预览弹层和成品弹层都使用相同层级，后渲染的成品弹层会遮住放大图。
6. P 页面文本框使用 `plan.prompt` 作为回退值，因此每次都有内置提示词。
7. 成品库图片没有统一的放大预览状态。
8. 账号数据只存在页面内存，编辑框没有头像上传入口，列表没有删除操作。

## 方案选择

采用浏览器本地持久化和浏览器文件系统写入的方案：

- 结构化、小体量数据写入 `localStorage`。
- 图片、头像和本地上传文件写入现有 IndexedDB 图片存储，结构化状态中只保存稳定引用。
- Chrome 或 Edge 在 HTTPS 生产站点中使用 File System Access API，把选中图片真实写入用户明确选择的目录。
- 不支持目录写入的浏览器使用逐张下载作为降级路径。

未采用的方案：

1. 全部数据写入 `localStorage`：图片和头像容易超过浏览器配额。
2. 服务端数据库和对象存储：能够跨设备同步，但超出“同一电脑长期保存”的范围，并增加部署和运维成本。

## 本地存储边界

### 关键词库

使用独立版本化键保存：

```ts
type KeywordLibraryState = {
  version: 1;
  customKeywords: string[];
  hiddenKeywords: string[];
};
```

- 添加关键词后立即保存，并从 `hiddenKeywords` 中移除同名词。
- 删除任意默认词或自定义词后立即保存到 `hiddenKeywords`，下次进入不再出现。
- 新生成或新增加的作品使用空 `tags`，关键词库只提供候选，不自动选择。
- 离开图片生成页再返回时，已经由用户手动选择的当前作品关键词仍随草稿恢复。

### 图片生成草稿

使用一个带版本号的草稿对象保存图片生成流程中的长期状态：

- 当前步骤和当前 P 页。
- 已选作品的标题、正文、风格和用户手动选择的关键词。
- 目标账号、内容类型、图片数量、模型和比例。
- P 页面定义、顺序、每页模型、比例、生成数量和用户输入提示词。
- 每页参考图引用、本地上传素材引用、素材库选择和产品素材选择。
- 已生成图片继续使用现有 IndexedDB 历史存储。

弹窗开关、加载状态、错误提示和拖拽中的临时状态不持久化。

页面首次挂载先完成草稿读取，再允许自动保存，避免默认初始值覆盖已有草稿。损坏或版本不兼容的数据只忽略该键并回退到安全默认值，不删除其他浏览器数据。

### 账号资料

账号列表使用独立版本化 `localStorage` 键保存。头像文件写入 IndexedDB，账号记录的 `avatar` 字段只保存稳定图片引用。页面加载时解析引用供 `<img>` 展示。

删除账号需要用户确认；确认后从持久化账号列表中删除。删除只影响账号管理资料，不级联删除历史成品内容。

## 关键词与默认提示词行为

进入新的文案生成结果或新建作品时，关键词全部保持未选择状态。切换候选作品时只同步标题、正文和风格，不复制候选的默认标签。

所有 P 页面提示词文本框默认空白：

- 现有 `plan.prompt` 不再作为文本框显示值或生成请求回退值。
- 新增 P 页面同样以空提示词开始。
- 用户已输入并保存到草稿的提示词在返回页面后恢复。
- 用户未填写提示词时按空字符串提交，由现有图片 adapter 采用自身基础生成规则；界面不再自动填入演示提示词。

## 图片生成页状态恢复

用户从图片生成页进入其他站内页面后，组件卸载前的可编辑内容已同步到浏览器存储。返回 `/content?tab=image` 时恢复图片生成步骤和全部草稿字段，不要求重新选择作品、P 页面或生成配置。

本地上传图片不能只保存 `blob:` URL。上传时先将文件写入 IndexedDB，再把稳定引用放入草稿；恢复时通过现有图片存储工具解析为可显示 URL。

## “保存本地”工作流

点击图片生成页“保存本地”后打开选图对话框：

1. 展示全部生成图片，默认不勾选。
2. 用户勾选一张或多张图片。
3. 用户点击“选择文件夹”，浏览器请求目录权限。
4. 用户点击“确认保存”，系统把勾选图片写入该目录。
5. 文件名使用 `P{页码}_{序号}.{扩展名}`，重复名称在当前操作中通过序号避免覆盖。

未勾选图片或未选择目录时禁用确认保存，并显示明确提示。写入过程中禁用重复提交；单张失败时报告失败数量和原因，不把仅选择目录描述为保存成功。

在支持 File System Access API 的 Chrome/Edge 上使用 `showDirectoryPicker()`、`getFileHandle()` 和 `createWritable()`。生产站点必须通过 HTTPS 提供。浏览器不支持目录写入时，隐藏目录写入确认流程并改为逐张下载勾选图片。

## 成品预览、手动选图和排序

点击“预览并打包成品内容”时：

- `finishedImageAssignments` 初始化为空，不再调用默认分图逻辑。
- 每个作品独立手动选择图片，图片不会自动分配到其他作品。
- 已选图片列表严格按照 assignment 数组顺序渲染，不再按 P 页二次排序。
- 已选图片支持在横向列表中拖动，拖到目标图片左侧或右侧后更新 assignment 顺序。

每个作品图片池的“全部”筛选右侧增加“上传图片”按钮。上传的图片写入 IndexedDB、加入公共图片池，并自动加入发起上传的当前作品已选列表；其他作品不会自动选择该图。

图片放大预览使用高于成品预览的独立顶层遮罩。无论从生成结果、已选列表还是图片池点击图片，放大层都显示在最上方，关闭后返回原成品弹窗状态。

## 成品内容库导出与放大

将按钮文案从“导入本地文件夹”改为“导出到本地文件夹”。导出范围规则固定为：

- 多选模式且已有勾选时，导出勾选作品。
- 其他情况下，导出当前筛选和当前文件夹下可见的作品。

每个作品在所选目录下创建经过文件名清理的独立子目录，并把真实图片按 `01`、`02` 等顺序写入。没有真实图片的作品跳过并计入结果提示，不用 mock 封面冒充真实图片。

不支持目录写入的浏览器降级为下载目标作品的真实图片。列表卡片和详情抽屉中的图片都改为按钮，点击后打开统一的顶层图片预览遮罩。

## 账号头像与删除

编辑账号弹窗增加头像预览和“上传头像”入口，只接受图片文件。选择后先显示预览，保存账号时持久化头像引用和其他账号字段。

账号列表操作列显示“编辑”和“删除”。删除按钮使用危险样式；用户确认后删除账号记录、关闭对应编辑状态并持久化新列表。取消确认不改变任何数据。

## 品牌文字范围

以下产品品牌文字统一修改：

- “小红书图文生产”改为“图文生产中台”。
- “Xiaohongshu Image Studio”改为中性的英文副标题或移除。
- “小红书图文生产状态”改为“图文生产状态”。
- “小红书选题列表”以及由平台名拼接出的同类页面标题改为“选题列表”。
- 页面 metadata、侧栏品牌区、状态卡和图文生产页标题一并修改。

平台筛选、账号平台、参考来源、发布平台、内容类型和模型提示中用于表达真实业务平台的“小红书”保留。

## 错误处理

| 场景 | 行为 |
|---|---|
| `localStorage` 数据损坏 | 忽略损坏键，使用默认值并允许后续重新保存 |
| IndexedDB 图片不存在 | 跳过该图片并显示缺失提示，不阻塞其他图片 |
| 用户取消文件夹选择 | 保持对话框和已选图片，不显示成功 |
| 目录权限被拒绝 | 显示权限提示，允许重新选择目录或使用下载降级 |
| 单张图片读取或写入失败 | 继续处理其他图片，最终显示成功数和失败数 |
| 浏览器不支持目录写入 | 下载用户已选的真实图片，不显示虚假的本地路径 |
| 账号头像文件不是图片 | 拒绝文件并保留原头像 |
| 浏览器存储配额不足 | 保留当前页面内存状态并提示清理本地图片历史 |

## 测试策略

### 单元测试

- 关键词添加、删除、隐藏和重新添加的状态转换。
- 新作品关键词默认为空，候选切换不会自动选词。
- 草稿版本校验、序列化和损坏数据回退。
- 选中图片的添加、移除和拖拽重排顺序。
- 保存图片的文件名清理、扩展名推断和目录写入调用。
- 成品库“优先多选，否则当前可见列表”的导出范围。
- 账号新增、编辑、删除和持久化状态转换。

### 集成和构建验证

- 现有 Node 测试全量通过。
- TypeScript 类型检查通过。
- Next.js 生产构建通过。
- 静态检查确认产品品牌位置不再出现旧品牌文案，同时业务平台字段仍保留。

### 浏览器验证

- 在部署站点使用 Chrome 或 Edge，填写关键词和图片页面草稿，切换路由后返回，确认内容完整恢复。
- 刷新页面并重新打开浏览器，确认关键词库、草稿、生成图、账号和头像仍存在。
- 勾选部分图片并写入用户选择目录，确认只出现勾选图片且文件可正常打开。
- 成品预览初始无图；手动选择、拖动排序、上传本地图后，保存到成品库的图片顺序一致。
- 从成品弹窗和成品库点击图片，确认放大层显示在最上方。
- 从成品库导出多选作品和当前可见作品，确认目录中包含真实图片。

## 验收标准

1. 手动添加和删除的关键词在同一浏览器长期生效；新作品不默认选择任何关键词。
2. 图片生成页离开后返回，所有需要继续编辑的内容和生成结果完整恢复。
3. 所有 P 页面默认提示词为空，用户已填写提示词能够恢复。
4. “保存本地”只保存用户勾选的图片，并真实写入用户选择的目录。
5. 成品预览不自动配图，用户可以手动选图、横向拖动排序并从本地上传图片。
6. 所有要求的图片入口都能在最上层放大预览。
7. 成品内容库能够把真实图片导出到本地，不再显示 mock 成功。
8. 账号头像、账号编辑和账号删除在刷新后仍保持正确状态。
9. 产品品牌统一为“图文生产中台”和“图文生产状态”，真实平台业务字段不受影响。
10. 功能在 HTTPS 部署站点的同一台电脑、同一个浏览器中可长期使用。
