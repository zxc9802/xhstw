# 小红书本机抓取扩展安装说明

这个扩展让抓取任务在使用者自己的 Chrome 或 Edge 中运行。网站服务器不登录小红书、不搜索或打开小红书详情，也不代理小红书图片和视频。抓取时会打开一个可见标签页，结果只写入当前网站在这台浏览器中的本地存储。

## 0.1.12 自定义抓取数量

- 关键词数量不再限制为 2 个。
- 每个关键词不再限制为 5 条，用户填写的数量会作为抓取目标。
- 不可浏览、重复或不符合筛选条件的候选会继续向后补抓；确实不足时会显示实际数量和目标数量。
- 详情间隔、关键词间隔、单任务锁和风控冷却仍然保留。

## 0.1.11 本机媒体保存

- 新抓取的正文图片、视频和视频封面会下载到当前浏览器站点数据中的专用 IndexedDB。
- 媒体仍显示在“爆款选题库”卡片内，不会进入左侧“素材库”。
- 清除该网站的浏览器站点数据会同时清除这些本机媒体文件。
- 删除选题会删除对应本机媒体；保留、取消保留和拒绝不会删除媒体。
- 单个媒体失败时，其余成功媒体和选题文案仍会保留，批次继续执行。
- 网页协议和扩展必须同时升级；旧扩展会显示“版本过低”。

### 从旧版升级

1. 先等待新版网页部署完成；网页和扩展协议必须同为版本 3。
2. 在 `chrome://extensions` 或 `edge://extensions` 停用或移除旧的解压扩展。
3. 解压 `xhs-browser-extension-0.1.12.zip`，开启开发者模式并点击“加载已解压的扩展程序”。
4. 选择解压后的 `xhs-browser-extension-0.1.12` 文件夹。
5. 后续替换文件时先在扩展管理页点击“重新加载”，再刷新生产网站。
6. 回到“爆款选题库”，确认状态显示“本机抓取已连接”后再开始抓取。

## 安装

1. 下载扩展 zip，并完整解压到一个固定目录。后续不要移动或删除这个目录。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展”，选择刚才解压且直接包含 `manifest.json` 的目录。
5. 在同一个浏览器中打开小红书并完成登录。
6. 重新加载生产网站，确认选题页显示“本机抓取已连接”。不需要点击扩展图标。
7. 第一次请只选择 1 个关键词、每个关键词 1 条，然后点击一次“开始抓取”。

执行期间不要关闭扩展创建的小红书标签页。任务成功后扩展会关闭该标签页并返回网站；如果出现登录、验证码或安全限制，标签页会保留，方便人工处理和诊断。

## 访问频繁或 300013

如果页面显示“安全限制”“访问频繁”或错误码 `300013`：

1. 立即停止当前抓取，不要连续重试。
2. 保留小红书标签页，核对页面上的真实提示。
3. 等待网站显示的 60 分钟本机冷却结束后再试。
4. 不要通过反复卸载、重装扩展或刷新页面来绕过冷却。

冷却只记录在发生问题的这台浏览器中，不会影响其他用户的浏览器。

## 更新

1. 在扩展管理页移除旧扩展。
2. 下载并解压新的 zip 到新目录。
3. 再次选择“加载已解压的扩展”。
4. 重新加载生产网站，确认显示“本机抓取已连接”。

## 移除

在 `chrome://extensions` 或 `edge://extensions` 中找到“小红书本机抓取助手”，点击“移除”。移除后网站会显示“未安装本机抓取扩展”，抓取按钮不可用；已有本地选题不会自动删除。

## 权限范围

扩展只访问打包时指定的网站 Origin 和 `https://www.xiaohongshu.com/*`，只申请 `storage` 权限。它不申请 Cookie、历史记录或全站访问权限，也不会执行网站下发的任意脚本。
